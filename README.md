# Epoche

Age of Socio Epoche: strategia in tempo reale in 15 epoche, dall'Età della Pietra ai robot.

**[Scarica Epoche per Windows](https://github.com/zeno20705-design/AgeOfSocio-Epoche-Download/releases/latest/download/Epoche-Windows.zip)**

Scompatta lo zip e apri `AgeOfSocio.exe`: il launcher controlla da solo gli aggiornamenti
prima di ogni partita e in alto fa scegliere tra Age of Socio ed Epoche.
Le istruzioni sono nel file `LEGGIMI.txt` dentro lo zip.
